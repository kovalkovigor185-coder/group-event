# Group Event — Running for Change

Адаптивная вёрстка главной страницы по макету **Group Event (Community)** для портфолио Kwork.

## Стек

Next.js (App Router), React, TypeScript (strict), SCSS Modules, Git.

## Запуск

```bash
npm ci
npm run dev
```

Открыть http://127.0.0.1:3000.

```bash
npm run typecheck
npm run build
```

Статическая сборка создаётся в `out/`. Все фотографии и шрифты локальные, без зависимости от временных ссылок Figma.

## Возможности

- Адаптивная главная страница: desktop, tablet, mobile.
- Навигация по разделам, состояния hover/focus и поддержка reduced motion.
- Доступные диалоги регистрации и подписки с HTML-валидацией, закрытием по Escape и возвратом фокуса.
- Формы демонстрационные: данные не отправляются и не сохраняются.

## Источник дизайна

[Group Event (Community), Figma Sites](https://www.figma.com/site/N4hZ73b1yN17EKGBzEJXLQ/Group-Event--Community-?node-id=0-3).

Учебная реализация готового community-макета. Дизайн, исходные тексты, дата события и изображения взяты из макета; работа в портфолио демонстрирует разработку, а не авторство дизайна. Реальное мероприятие или сбор пожертвований этим проектом не организуется.

Главная страница реализована как лендинг; пункты About Us и Events ведут к соответствующим разделам. Социальные значки заменены текстовыми символами. Отдельные страницы исходного макета `/about` и `/event` в эту работу не входят.
